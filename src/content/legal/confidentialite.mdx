Cette page concerne le site internet. Pour la box et vos photos, voir [notre engagement](/engagement/) : sans votre demande, nous n’avons pas accès à vos données.

## Ce que fait ce site aujourd’hui

<Checklist>

- Il ne dépose aucun cookie sur votre appareil. Un cookie est un petit fichier qu’un site enregistre dans votre navigateur, souvent pour vous reconnaître d’une visite à l’autre.
- Il n’utilise aucun traceur ni aucun outil de mesure d’audience.
- Il ne fait appel à aucun service extérieur : tout ce que votre navigateur charge (textes, images, polices de caractères, scripts) vient de ce site, et aucun autre serveur n’est contacté. Les liens vers d’autres sites ne s’ouvrent que si vous cliquez dessus.
- Le formulaire de commande est une démonstration : il n’envoie rien.

</Checklist>

Des tests automatiques vérifient, sur chaque page du site, qu’aucun cookie n’est déposé et qu’aucune requête ne part vers un autre site.

## Hébergement du site

Pour l’instant, le site est hébergé par GitHub Pages, un service de GitHub, Inc. D’après la <a href="https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages" hreflang="en">documentation de GitHub Pages (en anglais)</a>, l’adresse IP de chaque visiteur est enregistrée et conservée pour des raisons de sécurité ; GitHub n’indique pas pendant combien de temps. Le site, lui, ne dépose aucun cookie.
